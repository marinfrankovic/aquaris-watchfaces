Installation

01 / Guide

Download the release PRG from the watch-face page, then follow these steps. Install only the build labeled for your exact watch model.

  1. Check compatibility

    Use a build made for your exact watch model. R01 currently targets the fenix 8 AMOLED 47 mm with a 454 x 454 display. Keep your watch firmware up to date.

  2. Connect by USB

    Connect the watch to a Windows PC with a data-capable cable. Select file-transfer or MTP mode if prompted. Open the watch's internal storage in File Explorer.

  3. Transfer the file

    In the watch's internal storage, open the manufacturer-named folder, then its APPS subfolder. Copy AquarisR01.prg there. Do not copy test builds, source code, or debug files. Wait for the transfer to finish, then disconnect safely.

  4. Select the watch face

    Open the watch-face selection menu on the watch, select Aquaris R01, and apply it. Menu names vary by firmware. Use its Settings/Customize menu to choose the digital time zone, seconds, and right-side metric.

Updating an existing face

Switch to another watch face before replacing the same file. Avoid keeping an older build under a different filename. If you installed an early build with a different name, remove that old PRG before transferring AquarisR01.

Data and always-on display

Sync weather with your phone, enable wrist heart rate as needed, and enable Always On Display in the watch settings to use the low-power view. Missing readings appear as --. Brightness and gesture timing are controlled by the watch.

Reference: Official sideloading guide. These instructions describe USB sideloading, not an app-store installation.
